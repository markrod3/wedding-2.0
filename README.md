# wedding-2.0

Static site, no build step — just plain HTML/CSS/JS served directly.

## Layout

- `index.html` — root landing page, password-gated, links out to the sections below.
- `one-day/` — one-day wedding option page (`index.html`) and its `images/` assets.
- `two-day/` — two-day wedding option page (`index.html`) and its `images/` assets.
- `games/` — wedding games page (`index.html`) and its `images/` assets.

Each section is self-contained: its own `index.html` plus an `images/` folder for that section's assets.
